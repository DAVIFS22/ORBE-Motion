# ORBE Motion

ORBE Motion is a desktop motion-graphics and compositing application.

## Windows

1. Install the Rust stable toolchain for the MSVC target and the required Windows build tools.
2. Extract this repository to a writable folder.
3. Run `ORBE-MOTION-ABRIR.bat` to build and launch the application.
4. If startup fails, run `VERIFICAR-ORBE-MOTION.bat` and inspect the generated log.

## Brand

The application uses the ORBE Motion visual identity and dark-blue interface theme. Application icons are located in `assets/app-icon/`.
